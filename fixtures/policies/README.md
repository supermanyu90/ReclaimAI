# Policy corpus (synthetic)

Curated, dated guidance served by the Claim Copilot. Every file is fictional and says so.
Each file starts with a JSON metadata comment: `doc_id`, `version`, `institution` ("*" = any),
`asset_types`, `jurisdiction`, `effective_from`/`effective_to`, `source_url`, `review_status`,
`reviewed_on`. Sections are `## §n Title`; citations point to `doc_id@version §n`.
